# 现金流日历 — 功能设计

## 一句话定位

用**未来的视角**看现在的钱：把所有定期收支铺到日历上，提前看到未来每一天的余额变化，辅助当下决策。

## 核心场景

假设你月薪 6500，房租 2000，每天吃饭 120，每周还有几份兼职，下个月想换房子。你现在手上有 9170，换了房子之后现金流能不能撑住？

不用心算，不用 Excel，把事件录进去，日历和趋势图直接告诉你答案。

## 功能模块

### 1. 日历视图（月 / 周）

每一天的格子里显示当日余额。余额颜色分三级：绿色（安全）、黄色（预警，低于 1000）、红色（危险，为负）。格子底部有小圆点标记当天的事件：绿色是收入，红色是支出，橙色是模拟事件。

悬停任意一天，底部信息栏显示当日完整的收支明细。

### 2. 现金流趋势图

SVG 折线图横跨 270 天（过去 90 天 + 未来 180 天），紫色渐变填充。三个统计卡片一目了然：最低余额、最高余额、负余额天数。余额穿过零线时自动标出红色虚线。

鼠标悬停数据点展示当日余额和收支明细。

### 3. 事件管理

每个事件有类型（收入/支出）、金额、日期，可填写**分类**（如工资、餐饮、房租，供收支分析聚合）。支持四种周期模式：

| 周期 | 示例 |
|------|------|
| 每日 | 吃饭 -120/天 |
| 每周 | 兼职 300/周六 |
| 每月 | 工资 6500/20号 |
| 每年 | 保险 -5000/1月1日 |

周期事件可设永久或截止日期。周期事件可标记"可跳过单次"——勾选后，在日历悬停某天时可"跳过本日"，跳过某次发生，事件列表里可随时恢复。

### 4. 模拟模式（试错机制）

这个功能是整个应用的核心差异点。

在"换房子"这个场景里，你不知道搬到新地方之后现金流能不能扛住。于是你在模拟面板里添加虚拟事件：新房租金 -3000、搬家费 -5000、房租差价 -1000。这些事件以**虚线标识**出现在日历和趋势图上，不影响真实数据。

观察一段时间后，如果趋势图显示余额不会崩，你可以一键"转为真实事件"。如果会崩，删掉模拟事件，换个方案再试。

### 5. 收支分析

在日历和趋势图下方新增"收支分析"面板：
- **分类占比**：收入与支出分别按分类聚合为条形图，展示各分类金额与占比（无分类的归为"未分类"）
- **月度汇总表**：可见区间内每月的收入、支出、净额一览

### 6. 数据管理

- **导出备份**：下载 JSON 文件，包含所有事件和初始余额
- **导入备份**：恢复之前的全部数据
- **余额校准**：如果实际余额与计算结果不符，输入真实余额，自动反推初始基准
- **清除全部**：重置所有数据
- **自动保存**：所有数据实时写入 localStorage

## 典型工作流

1. 设定初始余额（你当前实际有多少钱）
2. 添加固定收入：工资、兼职等
3. 添加固定支出：房租、吃饭、贷款等
4. 观察日历和趋势图，确认未来现金流是否健康
5. 遇到不确定的决策（换房子、买大件），打开模拟模式
6. 添加模拟事件，观察影响
7. 决定后转为真实事件，或删除模拟

## 数据兼容

完全兼容旧版 JSON 格式，可直接导入历史备份数据。
